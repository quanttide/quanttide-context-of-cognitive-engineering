# 深度模式

**核心理念**：整合实体关系和抽象本体。核心优势在于手动和半自动能力，而非全自动化。

## 五步流程

1. **精炼消息** — 存"精炼消息"而非"原始消息"（扮演普通用户）
2. **识别意图** — 创作小说、设计产品等（扮演普通用户）
3. **识别本体** — 当前消息用到哪些知识本体？是否符合领域理解？（扮演知识工程师 + 领域专家，**核心功能**）
4. **识别实体** — 抽取结果是否合理？（扮演领域专家）
5. **验证抽取** — 结果是否比原始版本更有条理？（扮演普通读者）

## 关键约束

| 约束 | 值 |
|------|-----|
| LLM 角色 | 只提议不决定，用户始终有最终确认权 |
| 单次耗时 | ≤ 5 分钟 |
| 输入文本 | 200-500 字 |

## 差异化

> 其他系统的知识抽取功能是自动化的，只有这个系统需要具备手动和半自动的能力，可以给其他系统提供养料。
