# 思考云

> 碎片思考 → 结构化沉淀 → 可迁移知识

## 起源

创始人/知识工作者在日常工作中会产生大量思考碎片——战略判断、产品灵感、组织困惑、待办事项。这些碎片散落在备忘录、对话记录、文档碎片中，难以沉淀为可复用的知识资产。

最初有三个独立的产品构想试图解决这个问题：

| 产品 | 核心问题 | 解决方案 |
|------|---------|---------|
| **沟通云** | 碎片整理太耗时 | 精炼 + 意图 + 摘要 |
| **知识云** | 知识无法结构化 | 本体 + 实体 + 图谱 |
| **学习云** | 专家经验难传递 | 路径捕捉 + 认知地图 |

在深入梳理后发现，三者本质是**同一流水线的三种输出格式**，共享"碎片输入→精炼→意图"的前半段。于是合并为**思考云**——一个产品，三种模式。

## 核心流水线

```
原始碎片 → 精炼 → 意图 → 知识结构化 → 输出
                           ↓
                   轻量 / 深度 / 教学
```

每步详情见各意图文档。
